# TP N.º 2 · Unidad 4 · Direcciones

Alta, modificación y baja con confirmación de direcciones de entrega. Ingresá las coordenadas como latitud y longitud separadas por coma. Elegí la ciudad y la localidad en los desplegables. Las opciones corresponden a un catálogo de ejemplo. Si cerrás el formulario con la X o con Cancelar, los cambios se descartan.

## Ejecutar

Con Node.js 22.12 o superior, abrí una terminal en la carpeta del proyecto y ejecutá:

```sh
npm install
npm run dev
```

Abrí la dirección que muestra Vite en la terminal (normalmente http://localhost:5173).
Para compilar, usá `npm run build`.

Los cambios se guardan en `localStorage` y se conservan al recargar en el mismo navegador y puerto.
